# Practical execution evidence

Save screenshots captured during your own lab execution in this folder.

Suggested screenshots:
1. `ipconfig-pc1.png` — PC1 IP configuration.
2. `ping-pc1-to-pc2.png` — PC1 pinging PC2.
3. `ping-pc1-to-pc3.png` — PC1 pinging PC3.
4. `ipconfig-pc2.png` — PC2 IP configuration, if required by your instructor.

Do not use sample or fabricated screenshots as evidence of an actual test. If a ping fails, record the failure and troubleshoot it before reporting a successful result.
